Hammer-Aitoff projection

The Hammer-Aitoff projection maps the surface of a sphere onto an ellipse, preserving areas. Applied to a molecular structure, it gives a two-dimensional map of the whole surface of the system, as seen from its center, in a single figure. This is particularly useful for large, roughly spherical assemblies, such as viral capsids and envelopes, where any single view of the 3D structure hides half of the surface.

How the projection works

For each atom, the direction from a center (by default, the center of mass of the selection) to the atom is converted into a latitude \varphi \in [-\pi/2, \pi/2] and a longitude \lambda \in [-\pi, \pi]:

\varphi = \arcsin\left(\frac{z}{r}\right), \qquad \lambda = \operatorname{atan}(y, x)

where (x, y, z) are the coordinates of the atom relative to the center and r its distance to the center. These angles are then mapped onto the plane with

x_H = \frac{2\sqrt{2}\,\cos\varphi\,\sin(\lambda/2)}{\sqrt{1 + \cos\varphi\,\cos(\lambda/2)}}, \qquad
y_H = \frac{\sqrt{2}\,\sin\varphi}{\sqrt{1 + \cos\varphi\,\cos(\lambda/2)}}

so that all points lie inside the ellipse (x_H / 2\sqrt{2})^2 + (y_H / \sqrt{2})^2 \leq 1. Because the projection preserves areas, regions of the same size on the surface occupy the same area in the map, regardless of where they are.

Only the direction of each atom is used: atoms along the same line from the center fall on the same point of the map. The value shown in each region of the map is a statistic (mean, sum or count) of the values of all atoms projected onto it.

Projecting the atoms

hammer returns the projected coordinates of each atom. The input structure is not modified.

using PDBTools
atoms = read_pdb(PDBTools.test_file("structure.pdb"), "protein")
x, y = hammer(atoms)
x[1:3], y[1:3]

Heat maps of per-atom properties

plot_hammeraitoff projects the atoms, divides the map into nbins × nbins bins and colors each bin by a statistic of the values of the atoms that fell inside it. Any per-atom property can be used: B-factors, partial charges, contributions to coordination numbers, distances, etc. Plots must be loaded.

Here, each atom is colored by its distance to the center of mass, which highlights protrusions and cavities of the surface:

using Plots
c = center_of_mass(atoms)
dist = [sqrt((at.x - c[1])^2 + (at.y - c[2])^2 + (at.z - c[3])^2) for at in atoms]
plot_hammeraitoff(atoms, dist; nbins = 100, colorbar_title = "distance to center (Å)")

The statistic keyword defines how the values inside a bin are combined:

  • :mean (default): for intensive properties, such as B-factors or distances;
  • :sum: for additive properties, such as atomic contributions to a coordination number;
  • :count: number of atoms in each bin (the values are ignored).

To compare several structures on the same color scale, fix the limits with clims:

plot_hammeraitoff(atoms, dist; nbins = 100, clims = (0, 40), colorbar_title = "distance to center (Å)")

Contours of chains and groups of chains

With contours = :chain, a line is drawn around the region occupied by each chain:

plot_hammeraitoff(atoms, dist; nbins = 100, contours = :chain, colorbar_title = "distance to center (Å)")

With contours = :group, chains are grouped by a function that receives the chain name and returns the name of its group. This is useful when the structure has many copies of a few proteins (for example, the capsid and envelope proteins of a virus):

groups = Dict("A" => "protein 1", "B" => "protein 1", "C" => "protein 2")
plot_hammeraitoff(atoms, values; contours = :group, groupfun = ch -> groups[ch])

The figure can be saved directly with the outfile keyword, or with savefig.

Histograms without plotting

hammeraitoff returns the bin centers and the matrix of values used in the heat map, without plotting. hand_made_histogram builds the same kind of 2D histogram for any set of points.

xbin, ybin, cbins = hammeraitoff(atoms, dist; nbins = 100)
size(cbins)

Reference

PDBTools.hammer — Function
hammer(atoms; center = center_of_mass(atoms)) -> (x_hammer, y_hammer)

Project the atoms onto a plane using the Hammer-Aitoff equal-area projection.

The coordinates of each atom relative to center are converted to a latitude φ and a longitude λ (as seen from center), which are then mapped to planar coordinates. The projected points lie inside the ellipse (x / 2√2)^2 + (y / √2)^2 ≤ 1. Atoms located exactly at center have no defined direction and are placed at (0, 0).

The input atoms are not modified.

Arguments

  • atoms: a vector of PDBTools.Atom.
  • center: the point from which directions are measured (default: the center of mass).

Returns

Two vectors with the projected x and y coordinates of each atom.

Example

julia> using PDBTools

julia> atoms = read_pdb(PDBTools.test_file("structure.pdb"), "protein");

julia> x, y = hammer(atoms);

PDBTools.plot_hammeraitoff — Function
plot_hammeraitoff(atoms, values;
                  nbins=100,
                  statistic=:mean,
                  colormap=:tempo,
                  clims=nothing,
                  contours=:none,
                  groupfun=identity,
                  contour_color=:grey30,
                  colorbar_title="",
                  title="",
                  outfile=nothing)

Plot a heat map of values (one value per atom) using the Hammer-Aitoff projection.

Note

This function requires using Plots.

Keyword arguments

  • nbins: number of bins along each axis.
  • statistic: how the values inside a bin are combined: :mean, :sum or :count (see hand_made_histogram).
  • colormap: color map of the heat map.
  • clims: color limits as a tuple (min, max). If nothing, they are taken from the data.
  • contours: contour mode, one of
    • :none: no contours;
    • :chain (or :chains): draw one contour line around each chain;
    • :group: draw contours around groups of chains, where the group of a chain is given by groupfun(chainname).
  • groupfun: function mapping a chain name to its group (only used when contours=:group).
  • contour_color: color of the contour lines.
  • colorbar_title, title: texts of the color bar and of the plot.
  • outfile: if given, the figure is saved to this path.

Returns

The plot object.

Example

julia> using PDBTools, Plots

julia> atoms = read_pdb(PDBTools.test_file("structure.pdb"), "protein");

julia> plot_hammeraitoff(atoms, beta.(atoms); contours = :chain, colorbar_title = "B-factor")

PDBTools.hammeraitoff — Function
hammeraitoff(atoms, values; nbins=100, statistic=:mean) -> (xbin, ybin, cbins)

Project atoms with hammer and build the 2D histogram of values with hand_made_histogram. The statistic can be :mean, :sum or :count.

source
PDBTools.hand_made_histogram — Function
hand_made_histogram(x, y, values; nbins=100, statistic=:mean) -> (xbin, ybin, cbins)

Build a 2D histogram of values over the points (x[k], y[k]).

The bounding box of the points is divided into nbins × nbins equal bins. Each point is assigned to its bin, and the value of a bin is a statistic of the values of the points that fell inside it. Bins with no points get 0.0. Entries of values that are NaN or Inf are ignored.

Arguments

  • x, y: coordinates of the points.
  • values: one value per point.
  • nbins: number of bins along each axis.
  • statistic: how the values inside a bin are combined, one of
    • :mean: the mean of the values (default);
    • :sum: the sum of the values;
    • :count: the number of points in the bin.

Returns

  • xbin, ybin: the bin centers along each axis.
  • cbins: a matrix where cbins[j, i] is the value of the bin with center (xbin[i], ybin[j]).
